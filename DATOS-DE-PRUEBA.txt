 1. CÓMO ARRANCAR TODO
====================================================================
Desde la carpeta del proyecto (Venvios-Web):

    npm run dev

Eso levanta las dos partes a la vez:

    Web (frontend) . . . . . http://localhost:5173
    API (backend) . . . . . . http://localhost:4000/api/health

La base de datos (PostgreSQL) ya está creada, migrada y con datos
demo en esta máquina. Si algún día la borrás, restaurala con:

    docker compose up -d        (o el PostgreSQL local)
    npm run db:migrate
    npm run db:seed

 5. QUÉ PROBAR (GUIÓN RÁPIDO)
====================================================================
COMO CLIENTE:
    1. Entrar a /login con cliente@venviosexpress.com
    2. Ver casillero VEX-CUC-4827 y copiarlo
    3. Crear una prealerta nueva (tienda + descripción)
    4. Ver notificaciones de WhatsApp (destino enmascarado)

COMO OPERADOR (admin):
    1. Entrar a /login con admin@venviosexpress.com
    2. En "Prealertas" buscar una PENDIENTE y pulsar
       "Recibir en sede"
    3. Llenar peso y dimensiones -> el costo lo calcula el
       servidor solito y avisa al cliente por WhatsApp
    4. En "Paquetes" tocar una guía y avanzar el estado
       (bodega -> tránsito -> aduana -> entregado)
    5. En "Escáner" activar la cámara (requiere localhost o
       HTTPS) o buscar manualmente una guía

 6. PARA EL FUTURO: PRUEBAS DESDE EL TELÉFONO
====================================================================
A) MODO DESARROLLO (misma red WiFi que la PC):
       En el teléfono abrir  http://IP-DE-TU-PC:5173
       (ej: http://192.168.1.50:5173)
       Para eso, arrancar la web con:
           npm run dev -w frontend -- --host
       La cámara del escáner NO abre por IP sin HTTPS;
       usar la búsqueda manual de guía o el modo B).

B) MODO REALISTA (lo recomendado para probar cámara):
       Desplegar la web en un hosting con HTTPS
       (Vercel / Netlify / hosting propio con certificado).
       Con HTTPS la cámara, la foto de evidencia y todo el
       flujo del trabajador funcionan completo en el teléfono.

C) TODO lo demás (login, prealertas, recepción, estados,
   tarjetas móviles) ya funciona en cualquier pantalla,
   con o sin HTTPS.
